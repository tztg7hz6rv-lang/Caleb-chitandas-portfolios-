# Caleb Chitandas - Professional Portfolio Website

A modern, responsive portfolio website designed to showcase professional expertise in elite client relations, operations, and specialized care.

## 🌟 Features

- **Fully Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Professional Layout** - Modern UI with smooth animations and transitions
- **Easy to Customize** - Update your information directly in the HTML file
- **Interactive Elements** - Smooth scrolling, form validation, and mobile-friendly navigation
- **SEO Optimized** - Meta tags and semantic HTML for better search engine visibility
- **Fast & Lightweight** - Pure HTML, CSS, and JavaScript with no external dependencies

## 📋 Sections

1. **Navigation Bar** - Quick access to all sections with smooth scroll
2. **Hero Section** - Eye-catching introduction with call-to-action buttons
3. **About Me** - Professional summary and key strengths
4. **Experience** - Timeline of professional positions and achievements
5. **Skills** - Organized skill categories highlighting expertise
6. **Contact** - Direct contact information and message form
7. **Footer** - Professional footer with copyright

## 🚀 How to Use

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Or deploy to a web hosting service

### Customization

Edit the `index.html` file to update:

- **Personal Information**: Name, tagline, and descriptions
- **Contact Details**: Email, phone, and LinkedIn profile
- **Experience**: Job titles, companies, dates, and responsibilities
- **Skills**: Add or remove skill categories and individual skills
- **About Section**: Update your professional summary

### Deployment

Host this portfolio for free using:
- **GitHub Pages** - Push to a GitHub repository
- **Netlify** - Drag and drop your files
- **Vercel** - Connect your GitHub repository
- **Any Web Hosting** - Upload files via FTP

## 🎨 Customization Guide

### Colors

Edit the CSS variables in `styles.css` (`:root` section) to change colors:

```css
--primary-color: #1a1a2e;      /* Dark blue-black */
--highlight: #e94560;           /* Red accent */
--accent-color: #0f3460;        /* Deep blue */
```

### Fonts

To change fonts, modify the `font-family` property in the `body` CSS rule.

### Content

Update all text content directly in the HTML file between the opening and closing tags.
